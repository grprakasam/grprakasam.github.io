ADAM AI

Proof of concept on clinical data

A LangGraph agent turns a CDISC ADaM specification into an R program, runs it in a network-isolated sandbox, compares the output with an independent reference and stops for a person to sign off. Every step goes into a hash-chained audit log.

Workflow modernization agent

Track 1 of my agentic AI learning lab, built and tested offline

Converts legacy SharePoint- and Nintex-style workflows into Power Automate drafts. Deterministic rules go first and a bounded LLM second; anything left over is flagged for a person. A differential test then checks that each draft behaves like the original.

  • 0 silent failures in 29 behavioral testsevery difference traces back to a step that was already flagged
    Offline run, 12 synthetic workflows
  • 82% of actions converted by rules alone95% with the bounded LLM step, using hand-written stand-in replies
    Fixtures, not a live model

AI Exam Builder

Proof of concept for exam practice
